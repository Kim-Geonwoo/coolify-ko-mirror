coolify-ko

자체 호스팅 Coolify에 한국어 화면을 얹는 비공식 판입니다. 공식 이미지 위에 번역 파일만 덮고, 언제든 공식판으로 돌아갈 수 있습니다. 지금 판: 4.4.7

An unofficial Korean build of self-hosted Coolify. It keeps the official image and only adds translation files.

설치(이미 설치한 Coolify 서버에서)

curl -fsSL https://coolify-ko.geonwoo.dev/coolify-ko.sh -o coolify-ko.sh
curl -fsSL https://raw.githubusercontent.com/Kim-Geonwoo/coolify-korean/main/scripts/coolify-ko.sh.sha256 | sha256sum -c -
sudo bash coolify-ko.sh install

공식판으로 되돌리기

sudo bash /data/coolify/source/coolify-ko.sh uninstall

서명 확인

cosign verify --key https://raw.githubusercontent.com/Kim-Geonwoo/coolify-korean/main/releases/cosign.pub ghcr.io/kim-geonwoo/coolify-ko:4.4.7
